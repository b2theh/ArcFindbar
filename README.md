# Arc Findbar

Мод для Zen: поиск по странице в виде компактной панели вверху справа,
вдохновлённой Arc. Светлая и тёмная темы, скругления, мягкая тень,
счётчик совпадений, стрелки **↑ / ↓** и кнопка закрытия **×**.

Открытие — **⌘F** на macOS или **Ctrl+F** на Windows/Linux.
**Enter** переходит к следующему совпадению, **Shift+Enter** — к предыдущему,
**Esc** закрывает панель. Кнопки, поиск и локализация остаются штатными.
Панель накладывается на страницу и не сдвигает её содержимое.

## Установка через Sine (GitHub)

1. Отключите другие моды оформления поиска по странице.
2. Откройте **Настройки Zen → Sine Mods**.
3. Вставьте в поле установки из GitHub:

   ```text
   https://github.com/b2theh/ArcFindbar
   ```

4. Установите мод и полностью перезапустите Zen.
5. Нажмите **⌘F / Ctrl+F**.

Это CSS-мод: разрешение на JavaScript из неофициальных источников не нужно.
Если раньше добавляли ручной импорт этого мода в `userChrome.css`, удалите
его перед установкой через Sine.

## Ручная установка

1. Отключите другие моды оформления поиска по странице.
2. В `about:config` включите
   `toolkit.legacyUserProfileCustomizations.stylesheets`.
3. Через `about:support` откройте папку профиля Zen.
4. Скопируйте папку `ArcFindbar` в папку `chrome` внутри профиля
   (создайте `chrome`, если её ещё нет).
5. В начало `chrome/userChrome.css` добавьте:

   ```css
   @import url("ArcFindbar/chrome.css");
   ```

   Все импорты должны быть перед остальными CSS-правилами.
6. Полностью перезапустите Zen и нажмите **⌘F / Ctrl+F**.

Для удаления уберите импорт и перезапустите Zen.
JavaScript и изменения настроек самого поиска не требуются.
При установке через Sine удаление и отключение доступны в настройках Sine Mods.

## Настройка

В начале `chrome.css`: `--arc-find-width` — ширина (540px),
`--arc-find-offset` — отступ сверху и справа (16px).
Ширина автоматически ограничена шириной области страницы.
В разделённом просмотре панель находится внутри соответствующей области.

Строка дополнительных параметров поиска скрыта для компактности.
Сохранённые настройки учёта регистра, целых слов и подсветки продолжают действовать.
Чтобы поменять их штатными флажками, временно отключите импорт мода
и перезапустите Zen. Сообщения об отсутствии совпадений и переходе
через конец страницы отображаются под полем.

## Проверка

Селекторы, разметка кнопок и позиционирование в сетке сверены с исходниками
установленного Zen **1.24b**. Проверены синтаксис CSS и JSON-манифест.
Визуальную и интерактивную проверку выполняет пользователь:
светлая/тёмная тема, стрелки, Enter/Shift+Enter, Esc, отсутствие совпадений,
узкое окно и разделённый просмотр. Браузер автоматически не запускался.
